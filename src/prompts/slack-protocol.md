`slack://<workspace>/…`: Slack as read-only files for read/glob/grep (workspace = team name or id; bare `slack://` lists workspaces). `channels/` lists channels you're in, each file its recent history; `channels/<name or id>?limit=&oldest=&latest=`, `threads/<channel>/<ts>`, `users/<id or me>`, `canvases/<id>`, `files/<id>`, `search?q=<words>&scope=all&type=files&limit=`. Messages with replies link their thread URL. grep reads every channel it walks: name the channels. Sending and other changes go through `xd://slack`.
